# Закрытая выставка. 1898

Образовательная браузерная игра-квест для студентов НЭТИ. Игрок становится корреспондентом иллюстрированного журнала 1898 года и проходит частную галерею, где картины и исторические источники открывают путь в новые залы.

## Запуск и сборка

Требуется Node.js 20 или новее.

```sh
npm install
npm run dev
```

Production-сборка создаётся в `dist/`:

```sh
npm run build
```

Проверки: `npm run lint`, `npm test`, `npm run validate`.

## Папки проекта

- `src/engine`, `src/ui`, `src/tasks` — код игры.
- `src/data` — JSON-данные картин, залов, заданий, связей, подсказок и зон.
- `src/data/texts` — главы исторических текстов.
- `public/assets/paintings`, `public/assets/tasks`, `public/assets/audio` — подготовленные ресурсы игры, уже включённые в репозиторий.
- `api/leaderboard.php` — таблица рекордов для PHP-хостинга; на статическом GitHub Pages клиент использует `localStorage`.
- `tools` — извлечение материалов, проверка данных и описание заданий.
- `source/` — локальные оригиналы презентаций, документов и аудиозаписей преподавателя. Эта папка не публикуется в репозитории. Для повторного извлечения положите туда `картины по алфавиту.pptx`, `картины по темам.pptx`, `Игра задания.pptx` и оригинальные записи в `source/audio/`, затем установите Python-зависимости из `requirements.txt` и запустите `python tools/extract.py`. Готовые JSON и игровые ресурсы закоммичены, поэтому `/source` не нужен для установки, разработки и сборки игры.

GitHub Pages workflow запускается вручную в разделе Actions → Publish GitHub Pages → Run workflow. Pages не публикует этот приватный репозиторий на текущем тарифе. Для публикации на Pages потребуется сделать репозиторий публичным командой `gh repo edit --visibility public --accept-visibility-change-consequences`, затем в Settings → Pages установить источник GitHub Actions и вручную запустить workflow. Если репозиторий остаётся приватным, используйте Hostland.

Инструкции по размещению на GitHub Pages и Hostland находятся в [DEPLOY.md](DEPLOY.md).
